Mikrotik : Premier accès et configuration de base

Niveau : Débutant | Durée lecture : 15 min | Pratique : 1h

📚 Programme Complet Mikrotik

1. Se connecter au Mikrotik pour la première fois

Quand tu sors un Mikrotik du carton, il a déjà une IP par défaut : 192.168.88.1. On va s’y connecter avec Winbox.

Étape 1 : Télécharger et ouvrir Winbox

  1. Télécharge Winbox sur mikrotik.com/download
  2. Branche ton PC au port 2,3,4 ou 5 du Mikrotik avec un câble réseau
  3. Dans Winbox, clique sur l’onglet Neighbors. Tu verras ton routeur avec son adresse MAC
  4. Clique sur l’adresse MAC > Login : admin > Mot de passe : vide > Connect
Fig 1 : Première connexion via Winbox avec l’adresse MAC
⚠️ Important : Si tu ne vois pas le Mikrotik, désactive ton WiFi et ton pare-feu Windows le temps de la config.

2. Configurer l’accès Internet - WAN

On dit au Mikrotik où prendre Internet. 2 cas : soit ton modem donne déjà une IP en DHCP, soit tu as une IP fixe.

Cas 1 : DHCP Client - Le plus simple

  1. Dans Winbox : IP > DHCP Client > +
  2. Interface : choisis ether1 = c’est le port où tu branches le modem
  3. Coche Use Peer DNS et Add Default Route
  4. Clique OK. Si Status = bound, c’est bon.
Fig 2 : DHCP Client activé sur ether1 avec status bound

Cas 2 : IP Fixe

Si ton FAI t’a donné une IP fixe ex: 192.168.1.10/24, passerelle 192.168.1.1

/ip address add address=192.168.1.10/24 interface=ether1 /ip route add gateway=192.168.1.1 /ip dns set servers=8.8.8.8,1.1.1.1

3. Configurer le réseau local - LAN

Maintenant on crée le réseau pour tes clients. On va utiliser 192.168.88.1/24

  1. IP > Addresses > +
  2. Address: 192.168.88.1/24
  3. Interface: bridge ou ether2
  4. OK

Activer le DHCP Server pour que tes clients aient une IP auto

  1. IP > DHCP Server > DHCP Setup
  2. Interface : bridge > Next jusqu’à la fin
Fig 3 : Pool DHCP de 192.168.88.10 à 192.168.88.254

4. Activer le NAT - Partage Internet

Sans NAT, tes clients n’auront pas Internet. C’est la règle la plus importante.

/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
✅ Test : Branche un PC sur le port 2. Il doit recevoir une IP 192.168.88.x et avoir Internet. Teste ping 8.8.8.8 dans New Terminal.

5. Sécuriser : Changer le mot de passe admin

Ne laisse JAMAIS admin sans mot de passe. Un enfant de 10 ans peut hacker ton réseau.

  1. System > Users > double-clic sur admin
  2. Password > Mets un mot de passe fort > OK
Fig 4 : Change toujours le mot de passe par défaut
